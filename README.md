# BIZZOTTOCERAMICS — Free Starter Website

## Run it
1. Keep `index.html`, `style.css`, and `script.js` together.
2. Open `index.html` in a browser to preview.
3. Replace the sample product/gallery images with your real photos.
4. Update product names/details in `script.js`.

## Free hosting
You can publish this static website free with GitHub Pages:
1. Create a GitHub account.
2. Create a new public repository, e.g. `bizzottoceramics`.
3. Upload these files.
4. Repository → Settings → Pages → Deploy from branch → `main` → `/root`.
5. Save. GitHub will give you a free `github.io` website address.

Note: this starter version does not yet have a database/admin panel. Products are edited in `script.js`. A database-backed admin panel can be added later.
